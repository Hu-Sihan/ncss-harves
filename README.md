# NCSS Harves

NCSS Harves 是一个本地岗位查询与按需采集服务。软件使用专用 Chrome Profile 建立 NCSS 登录会话，通过 requests 串行采集岗位列表和详情，将完整岗位保存到 SQLite。

当前版本刻意保持精简：

- CLI 只有 `login` 和 `serve` 两个命令。
- HTTP 提供本地查询 `GET /query` 和远端按需采集 `GET /crawl`。
- 没有任务表、调度器、checkpoint、后台更新或 `query_or_crawl`。
- 首次初始化固定读取 NCSS 第 1～50 页，每页 `limit=20`。
- 岗位列表和详情全部串行请求，不并发访问 NCSS。
- 账号密码使用系统加密能力保存，不写入日志或普通文本文件。

## 1. 安装流程

### 1.1 环境要求

- Python 3.11 或更高版本
- Google Chrome
- Windows、Linux 或 macOS
- 可访问 `account.chsi.com.cn` 和 `www.ncss.cn`

Windows 使用当前用户绑定的 DPAPI 加密账密。Linux 和 macOS 使用系统 keyring 保存加密密钥；系统必须提供可用的密钥环服务。

### 1.2 创建并激活虚拟环境

PowerShell：

```powershell
cd F:\招聘\ncss-harves
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Linux 或 macOS：

```bash
cd /path/to/ncss-harves
python3 -m venv .venv
source .venv/bin/activate
```

### 1.3 安装

```bash
python -m pip install --upgrade pip
python -m pip install -e .
ncss-harves --help
```

如果终端找不到 `ncss-harves`，可使用等价入口：

```bash
python -m ncss_harves --help
```

## 2. 首次启动

```bash
ncss-harves serve --host 127.0.0.1 --port 9091
```

首次启动依次执行：

1. 创建 `data/ncss.db` 及数据库结构，初始化状态为未完成。
2. 在主线程提示输入 NCSS 账号和密码，密码使用隐藏输入。
3. 打开软件专用 Chrome，自动填写 CHSI 登录页。
4. 登录跳转到 `/student/exception.html` 时，自动进入 `/student/resume/personcenter.html`。
5. 导出 Cookie 和真实 User-Agent，使用 requests 验证 NCSS 第 6 页。
6. 第一次验证失败时等待 5 秒，重新导出 Cookie 并再验证一次。
7. 验证成功后显示登录成功，保存加密账密并关闭软件启动的 Chrome。
8. 在主线程串行拉取第 1～50 页，显示 `岗位列表 50/50` 进度条。
9. 按岗位 ID 去重后串行拉取全部详情，显示 `岗位详情 N/N` 进度条。
10. 单条详情失败时忽略该岗位；列表批次失败时整批不入库。
11. 所有详情结束后使用一个 SQLite 事务统一入库，并将初始化状态设为完成。
12. 初始化成功后才启动 HTTP 服务。

初始化过程中中断软件不会留下半批数据，下一次启动会重新执行完整初始化。

## 3. 后续启动

数据库已经初始化后，仍使用同一条命令：

```bash
ncss-harves serve --host 127.0.0.1 --port 9091
```

软件会读取加密账密，使用专用 Chrome 重建登录状态并验证第 6 页。成功后启动 HTTP，不会自动采集或启动后台更新；需要远端数据时调用 `/crawl`。

如果加密账密不存在、登录失败或第 6 页连续两次验证失败，服务不会继续启动，而是要求重新输入账号密码。

## 4. CLI 命令

### 4.1 `login`

作用：使用账号密码登录 NCSS，验证第 6 页，并保存加密账密文件。此命令不会初始化数据库或启动 HTTP。

```bash
ncss-harves login
ncss-harves login --username "你的账号"
```

参数：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--username` | 交互输入 | NCSS/CHSI 登录账号。 |
| `--credentials` | `data/ncss-credentials.key` | 加密账密文件路径。 |
| `--profile` | `data/chrome-profile` | 软件专用 Chrome Profile 路径。 |
| `--chrome-path` | 自动查找 | Google Chrome 可执行文件路径。 |

密码始终通过隐藏输入读取，不提供 `--password` 参数。只有第 6 页验证成功后才保存新账密；失败账密不会覆盖旧文件。软件只关闭自身启动的 Chrome，不扫描或关闭其他 Chrome 进程。

### 4.2 `serve`

作用：完成登录、必要的首次初始化，并启动本地查询与按需采集 HTTP 服务。

```bash
ncss-harves serve --host 127.0.0.1 --port 9091
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--host` | `127.0.0.1` | HTTP 监听地址。 |
| `--port` | `9091` | HTTP 监听端口。 |
| `--database` | `data/ncss.db` | SQLite 数据库路径。 |
| `--credentials` | `data/ncss-credentials.key` | 加密账密文件路径。 |
| `--profile` | `data/chrome-profile` | 软件专用 Chrome Profile 路径。 |
| `--chrome-path` | 自动查找 | Google Chrome 可执行文件路径。 |

等价入口：

```bash
python -m ncss_harves serve --host 127.0.0.1 --port 9091
```

## 5. HTTP 接口

### 5.1 `GET /query`

- 数据来源：仅本地 SQLite
- 鉴权：无；默认仅监听 `127.0.0.1`

```text
GET http://127.0.0.1:9091/query?jobName=产品经理&areaName=北京&jobType=实习&degreeName=本科&offset=1&limit=20
```

PowerShell：

```powershell
Invoke-RestMethod -Method Get -Uri "http://127.0.0.1:9091/query?areaName=北京&jobType=实习&offset=1&limit=20"
```

curl：

```bash
curl --get "http://127.0.0.1:9091/query" \
  --data-urlencode "areaName=北京" \
  --data-urlencode "jobType=实习" \
  --data-urlencode "offset=1" \
  --data-urlencode "limit=20"
```

### 5.2 `GET /crawl`

- 数据来源：NCSS 原生列表接口与岗位详情页
- 执行方式：全局 FIFO 队列，任意时刻只运行一个采集任务
- 写入规则：新岗位去重入库，已有岗位不覆盖

```text
GET http://127.0.0.1:9091/crawl?areaName=北京&jobType=实习&offset=1&limit=20
```

PowerShell：

```powershell
Invoke-RestMethod -Method Get -Uri "http://127.0.0.1:9091/crawl?areaName=北京&jobType=实习&offset=1&limit=20"
```

多值混合筛选示例：

```powershell
Invoke-RestMethod -Method Get -Uri "http://127.0.0.1:9091/crawl?areaName=北京,上海&jobType=全职,实习&property=国有企业,民营企业&offset=1&limit=6"
```

薪资显式多选示例：

```powershell
Invoke-RestMethod -Method Get -Uri "http://127.0.0.1:9091/crawl?monthPay=2K以下,面议&offset=1&limit=6"
```

全体随机筛选示例：

```powershell
Invoke-RestMethod -Method Get -Uri "http://127.0.0.1:9091/crawl?areaName=random&degreeName=random&jobType=random&limit=6"
```

`/crawl` 在本地展开多值枚举的笛卡尔积，但不会一次性构造整个组合数组。服务预先随机选择最多 `min(50, 组合总数)` 个不重复组合，每个组合串行请求 `limit` 条 NCSS 列表数据；每完成一个组合就按岗位 ID 做全局去重，唯一候选达到 `limit` 后立即停止请求新组合。唯一候选刚好等于 `limit` 时直接使用，超过 `limit` 时随机抽取 `limit` 条。如果所有已选组合请求完后仍不足 `limit` 条，则返回完整空结果，不查询详情缓存、不抓取详情，也不写入数据库。

数据库中 `description` 与 `detail_fetched_at` 均非空时复用详情缓存；否则按抽样结果顺序串行抓取详情。单条详情失败时忽略该岗位，不从未抽中的候选岗位补位。全部成功详情收集完成后才执行一次原子入库，再返回岗位。

已存在岗位仍会出现在本次响应中，只是不重复入库。缓存命中时使用本次列表中的最新名称、企业、薪资和发布日期，并合并缓存中的完整描述、详情地址和行业等字段。

### 5.3 筛选参数

所有枚举参数都使用人类可读名称，不接受 NCSS 编号。多个值使用英文逗号 `,`、中文逗号 `，` 或重复同名查询参数传递；省略、空值、`全部` 或 `不限` 表示不筛选。`/crawl` 会把每个枚举值转换成独立的 NCSS 合法单选，再在本地进行组合。

`areaName`、`degreeName`、`monthPay`、`jobType`、`property`、`companyType`、`recruitType` 和 `sourceName` 在 `/crawl` 中支持值 `random`。`areaName=random` 只展开全部 34 个省级单位；其他字段的 `random` 展开该字段的全部有效原生单选。与具体值同时出现时，`random` 覆盖具体值。`全部`、`不限` 表示不向 NCSS 发送该筛选。

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `jobName` | string | 空 | 岗位名称模糊匹配。 |
| `areaName` | enum[] | 全部 | 工作地点。显式值支持下列全部省级和市级单位；`random` 只选择省级单位。 |
| `degreeName` | enum[] | 全部 | 学历要求。 |
| `categoryName` | enum[] | 全部 | 职位类别。 |
| `industrySectors` | enum[] | 全部 | 所属行业，可使用大类或细分类。 |
| `jobType` | enum[] | 全部 | 工作类型。`工作` 等价于 `全职`。 |
| `property` | enum[] | 全部 | 单位性质。 |
| `companyType` | enum[] | 全部 | 企业标记。 |
| `monthPay` | string / enum[] | 空 | `/query` 对格式化月薪文本模糊匹配；`/crawl` 接受一个或多个下文列出的可读枚举。 |
| `recruitType` | enum[] | 全部 | 招聘信息类型。 |
| `sourceName` | enum[] | 全部 | 岗位来源。 |
| `publishDateFrom` | date | 空 | 仅 `/query`；发布日期下限，格式为 `YYYY-MM-DD`。 |
| `publishDateTo` | date | 空 | 仅 `/query`；发布日期上限，格式为 `YYYY-MM-DD`。 |
| `random` | boolean | `false` | 仅 `/query`；为 `true` 时随机排列查询结果。 |
| `offset` | integer | `1` | `/query` 为本地页码且不限制最高页数；`/crawl` 为 NCSS 页码，范围 `1`～`50`。 |
| `limit` | integer | `20` | 每页数量，范围为 `1`～`100`。 |

`offset` 是页码，不是行偏移量。数据库实际行偏移量为 `(offset - 1) × limit`。

`/crawl` 不接受 `publishDateFrom`、`publishDateTo` 或顶层布尔参数 `random=true`，传入时返回 HTTP 400。字段内枚举值（例如 `areaName=random`）按上述规则生效，其余可读枚举会自动转换为 NCSS 原生编号。

## 6. 按需采集规则

服务没有后台更新。每次 `/crawl` 独立执行以下流程：

1. 将每个可读多值筛选转换为独立原生选项，计算笛卡尔积总数。
2. 从平铺组合编号空间预先随机选择最多 `min(50, 组合总数)` 个不重复组合；认证恢复重试时复用同一组组合及其顺序。
3. 严格串行地按组合请求指定页，每个组合请求 `limit` 条列表数据。
4. 每个组合返回后立即按岗位 ID 做全局去重；唯一候选达到 `limit` 后停止请求剩余组合。
5. 唯一候选刚好等于 `limit` 时直接使用；超过 `limit` 时随机抽取 `limit` 条。若所有预选组合请求完后仍不足 `limit` 条，则返回 `jobs=[]`、`count=0`、`total=0`，不查询详情缓存、不抓取详情、不写库。
6. 仅对最终选中的岗位批量查询完整详情缓存，缓存缺失岗位串行拉取详情。
7. 单条详情失败时忽略且不补位；认证过期时自动账密登录一次，并从整个采集任务重新开始。
8. 全部详情在内存收集完成后检查取消状态，以一个事务插入数据库中不存在的新岗位。
9. 返回所有成功岗位，包括已有缓存岗位和新入库岗位。

组合抽样将每个平铺随机整数视为混合进制编码。第一个筛选维度是最低位：对于维度大小 `2 × 3 × 6`，依次执行 `% 2`、`// 2`、`% 3`、`// 3`、`% 6`，即可得到三个维度的选项位置。服务只从 `range(组合总数)` 抽取 `k = min(50, 组合总数)` 个唯一整数，不生成完整笛卡尔积；组合索引及解码的时间复杂度为 `O(k × d)`，额外组合内存为 `O(k + d)`，其中 `d` 是筛选维度数。列表候选内存随实际请求到的唯一岗位数线性增长。

客户端关闭 TCP 连接时，对应排队或运行中的任务会取消，内存结果全部作废，不允许部分入库。Python 线程采用协作式取消；正在执行的单次网络请求最多等待其返回或 10 秒超时。SQLite 已进入提交阶段时等待短事务完成。

## 7. 正常关闭

按 `Ctrl+C`、收到 `SIGTERM` 或 Windows `SIGBREAK` 后：

1. 立即设置停止标志，不再接受新的 `/crawl`。
2. 取消排队和运行中的采集任务；尚未发送响应的 `/query` 与 `/crawl` 返回完整空结果。
3. 当前网络请求最多等待其 10 秒超时边界。
4. 关闭 HTTP、爬取工作线程、软件启动的 Chrome 和 requests Session。
5. 未提交的内存结果全部作废。
6. 如果 SQLite 正在提交事务，则等待提交结束后退出，避免半批数据。

Python 不会强制杀死工作线程。任务管理器强制结束进程或断电无法执行清理回调，但 SQLite 事务和 WAL 会避免写入半条业务数据。

## 9. 故障排查

### 找不到 `ncss-harves`

确认已经激活安装时使用的虚拟环境，或改用：

```bash
python -m ncss_harves --help
```

### 找不到 Google Chrome

指定可执行文件：

```powershell
ncss-harves serve --chrome-path "C:\Program Files\Google\Chrome\Application\chrome.exe"
```

也可以设置环境变量 `NCSS_HARVES_CHROME_PATH`。

### 专用 Profile 被占用

确认没有另一份 NCSS Harves 正在使用相同的 `data/chrome-profile`。软件不会通过进程名关闭未知 Chrome，也不会强制抢占 Profile。

### 登录后仍无法访问第 6 页

软件会等待 5 秒重新导出 Cookie 并验证一次。如果仍失败，会关闭本次 Chrome 并要求重新输入账密。请确认 CHSI 登录成功，且浏览器能够进入 NCSS 个人中心。

### 数据库一直未初始化

首次初始化只有在 50 页列表和全部可用详情完成，并且统一事务提交成功后，才会写入 `initialized=true`。检查控制台 ERROR 日志中的列表请求、网络或数据库错误；修复后重新执行 `serve`。

### `/crawl` 返回空岗位

确认筛选条件在 NCSS 网页端存在数据，并检查 HTTP 状态码。HTTP 200 且 `total=0`、`count=0` 时，可能表示最多 50 个随机组合或整个组合空间请求完后仍没有凑足 `limit` 条唯一候选；`total` 大于 0、`count` 为 0 时，表示候选数量充足，但最终抽中的岗位详情均获取失败。HTTP 502 表示列表请求、响应结构或自动重新登录失败。失败批次不会写入部分数据。
